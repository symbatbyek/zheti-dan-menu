Lucide icon rendered as a CSS mask so it inherits `currentColor`; use for every glyph in the system.
```jsx
<Icon name="flame" size={16} />
<Icon name="map-pin" label="Адрес" />
```
Names: https://lucide.dev/icons. Sizes: 16 inline/tags, 20 buttons, 24 nav/app bar.

Brand logos: `<Icon name="brand:whatsapp" style={{color:'#25D366'}} />` — loads from Simple Icons (filled glyph). Use only for third-party brands (WhatsApp, Telegram); keep Lucide for everything else.
