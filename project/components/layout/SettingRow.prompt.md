56px+ row with title, optional subtitle and trailing control — for toggles and navigation inside a ListGroup.
```jsx
<SettingRow title="Қолжетімді" subtitle="Тағамға тапсырыс беруге болады" control={<Switch checked />} />
<SettingRow icon="clock" title="Жұмыс уақыты" subtitle="08:00–23:00" onClick={open} />
```
