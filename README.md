# Жеті Дән · QR menu

A digital QR menu for a small café: guests scan a code and see the menu in Kazakh, Russian, English or Chinese; the owner edits dishes from their phone.

| Folder | What's inside |
|---|---|
| [`app/`](app/) | The working web app (Vite + React + TypeScript). Start here — see [`app/README.md`](app/README.md). |
| [`project/`](project/) | The original Claude Design export: design system, tokens, components, prototypes, photos. |
| [`chats/`](chats/) | The design conversation the project came from. |
| [`HANDOFF.md`](HANDOFF.md) | Notes that came with the Claude Design export. |

## Run locally

```bash
cd app
npm install
npm run dev
```

Guest menu: http://localhost:5173 · Owner panel: http://localhost:5173/owner.html
